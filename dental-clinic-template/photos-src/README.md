Put the clinic's original photos here (any size), named by where they go:

- `hero.jpg` — clinic interior or doctor at work (landscape)
- `doctor.jpg` — lead doctor portrait (portrait, 4:5)
- `team-1.jpg`, `team-2.jpg` — other doctors
- `before-1.jpg`, `after-1.jpg`, … — before/after cases (same framing for each pair)
- `logo.svg` or `logo.png`

Then run `npm run images`. Optimised files appear in `public/images/`.
Files in this folder are not committed to git (see .gitignore).
