# ÉCLAT — The Art of Forever

موقع مجوهرات فاخر ثلاثي الأبعاد (React + Vite + TypeScript + React Three Fiber + GSAP).
مشروع عرض ضمن بروفايل أعمال؛ ÉCLAT علامة خيالية ولا يوجد بيع حقيقي.

## محتويات الحزمة

| المجلد | الوصف |
|---|---|
| `site/` | **نسخة جاهزة مبنية** — ارفع محتواها كما هو على أي استضافة ثابتة (يعمل داخل مجلد فرعي) |
| `src/`, `index.html`, `package.json`, `package-lock.json`, `vite.config.ts` | ملفات المصدر والاعتماديات |
| `public/` | الأصول: نماذج 3D (`models/*.glb`)، الإضاءة (`env/*.hdr`)، الصور (`img/`) |
| `blender/` | سكربتات Blender التي أنشأت النماذج والصور (اختيارية) |
| `scripts/`, `tests/` | توليد الصور، واختبارات Playwright (اختيارية) |
| `.github/workflows/deploy-pages.yml` | نشر تلقائي على GitHub Pages |

## التشغيل محليًا

المتطلبات: Node.js 20 أو 22.

```bash
npm ci            # أو npm install
npm run dev       # http://127.0.0.1:5173
npm run build     # يبني النسخة النهائية في dist/
npm run preview   # يعرض dist/ على http://127.0.0.1:4173
```

ملاحظة: لا تفتح `site/index.html` مباشرة بالنقر المزدوج (file://) — المتصفحات تمنع تحميل نماذج 3D بهذه الطريقة.
استخدم أي خادم بسيط، مثلًا: `npx serve site` أو `python3 -m http.server` داخل مجلد `site`.

## النشر على GitHub Pages

### الطريقة 1 — تلقائيًا (موصى بها)
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `eclat`) وارفع **محتوى هذا المجلد** إلى جذره على فرع `main`.
2. من المستودع: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. أي دفع إلى `main` يبني الموقع وينشره. الرابط سيكون: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

### الطريقة 2 — يدويًا بدون بناء
ارفع محتوى مجلد `site/` إلى فرع `gh-pages` (أو مجلد `docs/` على `main`)، ثم من **Settings → Pages** اختر ذلك الفرع/المجلد.

المسارات نسبية (`base: './'`) لذلك يعمل الموقع في الجذر أو داخل أي مجلد فرعي دون تعديل.

## الخدمات والمفاتيح الخارجية

**لا يحتاج المشروع أي خدمة خارجية أو مفتاح API.** الخطوط مستضافة ذاتيًا، والنماذج والصور داخل الحزمة،
ولا توجد طلبات لأي نطاق خارجي. نموذج "Private Viewing" عرض توضيحي فقط ولا يرسل أي بيانات.
إذا أردت لاحقًا ربطه بخدمة بريد أو CRM، فليكن ذلك عبر خادم/دالة سيرفر تحفظ المفتاح — لا تضع مفاتيح سرية في كود الواجهة.

## ملاحظات قبل العرض العام

- الصفحة تحتوي `<meta name="robots" content="noindex, nofollow">` (لا تظهر في محركات البحث). احذفها من `index.html` إن أردت الفهرسة.
- الصور الخمس التي تبدأ بـ `client_` في `public/img/` مأخوذة من صور مرجعية قدّمها العميل وحقوق استخدامها **غير مؤكدة** — تأكد منها أو استبدلها قبل النشر العام (انظر `ASSETS.md`).
- لم تُضمَّن الصور الخام الأصلية للرندر (`assets-src/`) لأنها ليست مطلوبة للتشغيل (~100MB).
